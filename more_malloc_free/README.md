# C - More malloc, free

This project covers `exit`, `calloc` and `realloc`, and more practice with `malloc` and `free`.

## Tasks

- `0-malloc_checked.c`: allocates memory with `malloc` and exits with status 98 on failure.
- `1-string_nconcat.c`: concatenates s1 with the first n bytes of s2.
- `2-calloc.c`: allocates zeroed memory for an array using `malloc`.
- `3-array_range.c`: creates an array of integers from min to max.
