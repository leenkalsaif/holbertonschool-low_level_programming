# C - Pointers, arrays and strings

This project covers pointers to pointers, multidimensional arrays and common string functions in C, without using the standard library.

## Requirements

- Compiled on Ubuntu 20.04 LTS with `gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
- Betty coding style
- No global variables
- No more than 5 functions per file
- Only `_putchar` is allowed for output

## Files

| File | Description |
|------|-------------|
| `main.h` | Header file with all function prototypes |
| `0-memset.c` | `_memset`: fills memory with a constant byte |
| `1-memcpy.c` | `_memcpy`: copies memory area |
| `2-strchr.c` | `_strchr`: locates a character in a string |
| `3-strspn.c` | `_strspn`: gets the length of a prefix substring |
