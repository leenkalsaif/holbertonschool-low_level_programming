# Simple Calculator

A small command-line calculator written in C.

## Usage
1
cat README.md
0


cat README.md

## Features

- Displays a menu
- Quit with option `0`
- Menu loops until the user quits
- Invalid choices print `Invalid choice`
- Addition (option `1`): prompts for `A` and `B`, prints `Result: <value>`
- Subtraction (option `2`): prints `A - B`
